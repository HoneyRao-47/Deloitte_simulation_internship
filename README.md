# Daikibo Data Analytics Virtual Experience

This repository contains solutions for the Daikibo Data Analytics Virtual Experience Program.

## Task 1: Telemetry Dashboard
- Imported nested JSON telemetry data into Tableau.
- Created interactive dashboards to monitor factory downtime.
- Identified the factory with the highest unhealthy device count.

## Task 2: Equality Analysis
- Classified employee Equality Scores into Fair, Unfair, and Highly Discriminative categories.
- Implemented Excel formulas for automated classification.
- Produced a clean HR analytics dataset.

## Tools Used
- Tableau Public
- Microsoft Excel
